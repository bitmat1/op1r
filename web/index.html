op1r – OP-1 custom firmware

Turns the original Teenage Engineering OP-1 firmware R246 (op1_246.op1) into the op1r custom firmware. Everything runs in your browser: your firmware file is not uploaded anywhere.

  1. Get the original op1_246.op1 from teenage.engineering.
  2. Drop it below (or click to choose it) and wait about half a minute.
  3. Download the result and install it like any OP-1 update (bootloader update mode).
